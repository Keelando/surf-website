# Backend Connection Guide

The frontend and backend live in the same monorepo.

## Repository Structure

```
envcan_wave/                     # Monorepo root
├── scripts/                     # Data collection and export scripts
├── lib/                         # Shared Python utilities (config, stations)
├── config/                      # Station configs, sr3 subscriptions
├── site/                        # Static frontend (served by Caddy)
│   ├── index.html, tides.html, forecasts.html, ...
│   ├── assets/js/               # JavaScript that fetches JSON data
│   └── data/                    # JSON files generated by backend scripts
└── ...
```

## Data Flow

1. **Backend** (repo root):
   - `buoy_to_influx_sqlite.py` -> Collects wave buoy data
   - `tide_to_sqlite.py` -> Collects tide data
   - `sqlite_to_json.py` -> Exports `site/data/latest_buoy_v2.json`
   - `export_tide_json.py` -> Exports `site/data/tide-*.json`

2. **Frontend** (`site/`):
   - `assets/js/main.js` -> Fetches `data/latest_buoy_v2.json`
   - `assets/js/tides.js` -> Fetches `data/tide-*.json`
   - `assets/js/charts.js` -> Renders data visualizations

## Cross-Stack Development

When adding a feature that spans both backend and frontend (e.g., new wave stations):

1. **Backend** (repo root):
   - Add data collection scripts
   - Set up database schema
   - Create JSON export
   - Test that data flows to `site/data/`

2. **Frontend** (`site/`):
   - Update JavaScript to consume new JSON
   - Add UI elements
   - Test the integration

Everything is in one commit now — no cross-repo linking needed.

## JSON Data Contracts

**Buoy Data** (`site/data/latest_buoy_v2.json`):
```json
{
  "4600146": {
    "buoy_id": "4600146",
    "wave_height_sig": 2.5,
    "wind_speed": 15.3,
    "observation_time": "2025-11-06T08:30:00Z"
  }
}
```

**Tide Data** (`site/data/tide-latest.json`, `tide-timeseries.json`, `tide-hi-low.json`):
- See `docs/ARCHITECTURE_DETAILED.md` for schema details

## Testing the Connection

```bash
# Verify JSON files are being generated
ls -lh site/data/

# Check latest buoy data
cat site/data/latest_buoy_v2.json | jq .

# Check tide data
cat site/data/tide-latest.json | jq .

# Monitor backend logs
tail -f logs/*.log
```

## Quick Reference

**When to work in each area:**
- **Backend** (repo root): Change data structure, add new stations, debug missing data
- **Frontend** (`site/`): Change UI/display, update styling, modify charts
- **Both**: Add new data types, change JSON contracts
